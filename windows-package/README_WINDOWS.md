# Banetskaya.by — установка на Windows

Есть два пути. **Способ A** (рекомендуется) даёт готовый установщик `BanetskayaSetup.exe`,
который ставится в один клик — конечному пользователю **не нужны** Python и Node.

---

## Способ A. Готовый установщик `.exe` (рекомендуется)

Установщик собирается автоматически в облаке через **GitHub Actions** (на Windows‑раннере).
Отдельный компьютер с Windows для сборки **не требуется**.

### Как получить `BanetskayaSetup.exe`
1. В Emergent нажмите **«Save to GitHub»** — код (вместе с готовым workflow) уедет в ваш репозиторий.
2. Откройте репозиторий на GitHub → вкладка **Actions** → workflow **«Build Windows Installer»**.
   Он запустится автоматически при пуше (или запустите вручную кнопкой **Run workflow**).
3. Дождитесь зелёной галочки (5–10 мин). Внизу страницы запуска, в разделе **Artifacts**,
   скачайте **`BanetskayaSetup`** — внутри `BanetskayaSetup.exe`.

Что делает workflow (файл `.github/workflows/windows-installer.yml`):
- собирает фронтенд в статику (`yarn build`);
- упаковывает бэкенд + Python в один набор через **PyInstaller**;
- скачивает портативную **MongoDB** (`mongod.exe`) и кладёт её внутрь;
- собирает единый установщик через **Inno Setup**.

### Установка и запуск (у конечного пользователя)
1. Двойной клик по **`BanetskayaSetup.exe`** → «Далее» → «Установить».
2. Запуск с ярлыка на рабочем столе / в меню «Пуск». Откроется браузер на `http://127.0.0.1:8001`.
   - Внутри уже встроена локальная база (MongoDB) — ничего ставить не нужно.
   - Данные хранятся локально: `%LOCALAPPDATA%\Banetskaya\data`.

### Один момент про PDF/печать
Формирование **PDF** и **печать** используют бесплатный **LibreOffice**. Установите его один раз:
https://www.libreoffice.org/download/ — программа сама найдёт его по стандартному пути.
**Word (.docx)** формируется всегда, даже без LibreOffice.

## Способ B. Запуск из исходников (для разработчика)

Если нужен запуск без сборки установщика.

### Что установить один раз
1. **Python 3.11** (при установке — галочка **«Add Python to PATH»**) — https://www.python.org/downloads/
2. **Node.js LTS** — https://nodejs.org/ , затем в командной строке: `corepack enable`
3. **MongoDB Community** (как служба на `localhost:27017`) — https://www.mongodb.com/try/download/community
4. **LibreOffice** (для PDF/печати) — https://www.libreoffice.org/download/

### Шаги
1. Скопируйте папку проекта на компьютер.
2. В папке `windows-package` запустите **`setup.bat`** (создаст окружение, поставит зависимости,
   соберёт фронтенд, подготовит `.env`).
3. При необходимости поправьте `backend\.env` → `SOFFICE_BIN` (путь к `soffice.exe`).
4. Запустите **`start.bat`** → откроется `http://127.0.0.1:8001`.

## Частые вопросы

**GitHub Actions не запускается / нет вкладки Artifacts.**
Убедитесь, что workflow есть в репозитории (`.github/workflows/windows-installer.yml`) и что
Actions включены в настройках репозитория. Для приватных репозиториев нужен доступ к GitHub Actions.

**PDF не формируется / ошибка при печати.**
Не установлен LibreOffice или он в нестандартной папке. Установите LibreOffice; при необходимости
задайте переменную окружения `SOFFICE_BIN` с полным путём к `soffice.exe`.

**Порт 8001 занят.**
Закройте программу, занявшую порт, либо измените порт (в способе B — в `start.bat` и `frontend\.env`,
затем пересоберите фронтенд через `setup.bat`).

**Где данные?**
Способ A — `%LOCALAPPDATA%\Banetskaya\data`. Способ B — в вашей локальной MongoDB.

**Важно:** шаблон договора (`backend\templates\contract_template.docx`) остаётся **1:1** как в исходном
Word — подставляются только переменные поля.
