# Banetskaya.by — запуск на Windows

Эта папка содержит всё необходимое, чтобы запустить приложение (автозаполнение договоров найма из Excel) на обычном компьютере с Windows 10/11.

---

## 1. Что нужно установить один раз (бесплатно)

1. **Python 3.11** — https://www.python.org/downloads/
   - ⚠️ При установке отметьте галочку **"Add Python to PATH"**.
2. **Node.js LTS** (включает менеджер пакетов) — https://nodejs.org/
   - После установки откройте «Командную строку» и включите Yarn:
     ```
     corepack enable
     ```
3. **MongoDB Community Server** — https://www.mongodb.com/try/download/community
   - Установите как службу (Run service as Network Service) — она сама будет работать на `localhost:27017`.
4. **LibreOffice** — https://www.libreoffice.org/download/
   - Нужен для формирования **PDF** и **печати**. Word (.docx) работает и без него.

---

## 2. Установка приложения

1. Скачайте/скопируйте всю папку проекта на компьютер (кнопка **Save to GitHub** в Emergent → затем скачать ZIP из GitHub, либо экспорт кода).
2. Откройте папку `windows-package`.
3. Дважды кликните **`setup.bat`**. Скрипт сам:
   - создаст окружение Python и установит зависимости бэкенда,
   - подготовит файлы `.env`,
   - соберёт фронтенд.
   Дождитесь надписи «Установка завершена».
4. Откройте файл `backend\.env` в Блокноте и при необходимости поправьте строку
   `SOFFICE_BIN` — путь к `soffice.exe` (по умолчанию `C:\Program Files\LibreOffice\program\soffice.exe`).

---

## 3. Запуск

Дважды кликните **`start.bat`**.
- Запустится локальный сервер, и через несколько секунд откроется браузер по адресу **http://127.0.0.1:8001**.
- Чтобы остановить приложение — закройте чёрное окно консоли.

---

## 4. Как пользоваться

- **Генерация** — загрузите Excel со студентами (кнопка «Скачать шаблон Excel» даст образец), выберите нужных, сформируйте договоры (Word/PDF, поштучно или пакетом).
- **Редактор договора** — правьте поля и пункты с живым PDF-предпросмотром, сохраняйте черновики.
- **История** — поиск, повторное скачивание/печать, фильтр «Готовые/Черновики».
- **Настройки** — образец Excel, демо-данные, пресеты полей.

Шаблон договора (`backend\templates\contract_template.docx`) остаётся **1:1** как в исходном Word — подставляются только переменные поля.

---

## 5. Частые вопросы

**PDF не формируется / ошибка при печати.**
Не установлен LibreOffice или неверный путь в `backend\.env` (`SOFFICE_BIN`). Установите LibreOffice и укажите путь к `soffice.exe`.

**Не запускается: «python не является внутренней командой».**
Python установлен без галочки «Add to PATH». Переустановите Python с этой галочкой.

**Не собирается фронтенд: «yarn не найден».**
Выполните в командной строке `corepack enable` (входит в Node.js).

**Порт 8001 занят.**
Закройте другое приложение на этом порту или измените порт в `start.bat` и адрес в `frontend\.env` (после смены — снова выполните сборку через `setup.bat`).

**Где хранятся данные?**
В локальной базе MongoDB на вашем компьютере (`localhost:27017`).
