### РЕШЕНИЯ ПОЛЬЗОВАТЕЛЯ (подтверждены):
- **1a** — ПОЛНАЯ ВЕКТОРНАЯ ОТРИСОВКА: приложение само рисует весь бланк (рамки, надписи) + данные

- **3a** — РЕАЛЬНЫЙ размер 105×145 мм, размещать на листе A4 (не растягивать).
- **ВАЖНО (имплозиция):** ВСЕГДА печатать по 2 листка на человека. Значит на лист A4 класть
  «по 2 или по 4» копии формы 105×145. На 1 человека = 2 копии листка.
- **4a** — ОБЕ стороны: лицевая (поля 1–9) + оборотная (поля 10–15). Двусторонняя печать / 2 страницы.

### ГЕОМЕТРИЯ ЛИСТА A4 (важно для имплозиции):
- Форма 105×145 мм. A4 = 210×297 мм.
- 2 формы по ширине: 105×2 = 210 = ровно ширина A4 (145 мм по высоте).
- 4 формы: сетка 2×2 = 210 × 290 мм (145×2=290 < 297) → 4 формы влезают в A4.
- Т.е. лист A4 = сетка 2×2 из форм 105×145 в реальном размере.

### ⚠️ ОТКРЫТЫЙ ВОПРОС (СПРОСИ ПОЛЬЗОВАТЕЛЯ ПЕРЕД ФИНАЛОМ ПЕЧАТИ):
Как именно раскладывать 2 стороны + 2 копии/чел + duplex? Не выяснено до конца. Варианты:
- На 1 человека: лист «лицо» = 2 одинаковые ЛИЦЕВЫЕ рядом; лист «оборот» = 2 ОБОРОТНЫЕ, выровненные
  под них для двусторонней печати; duplex → 2 готовых двусторонних листка, разрезать пополам.
- Режим «4 на листе» = 2 человека на лист (по 2 копии каждому) — заполнить сетку 2×2.
Рекомендация: сделать генерацию PDF, где СТРАНИЦА 1 = A4-сетка лицевых, СТРАНИЦА 2 = A4-сетка оборотных
(в тех же позициях, для duplex «переворот по длинному краю»). Печать 100%. Подтверди у пользователя
порядок дуплекса (по длинному/короткому краю) и сколько копий/чел по умолчанию (2).
